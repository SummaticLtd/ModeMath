# Fonts

`latinmodern-math.otf` is Latin Modern Math 1.959, from CTAN's `lm-math`, under the GUST Font License
in `GUST-FONT-LICENSE.txt`. It is embedded in ModeMath.dll as `ModeMath.latinmodern-math.otf`.

`AMS-Capital-Blackboard-Bold.otf` draws the blackboard bold capitals, which Latin Modern has no shapes
for. Its name table records it as extracted by Happypig375 in 2018 from `AMSMathematicalSymbol-Medium5`,
Copyright (c) 1997, 2009 American Mathematical Society, with Reserved Font Name MSBM9 — wording of the
SIL Open Font License 1.1, which AMSFonts is issued under and whose reserved names include `msbm9`.
`AMSFONTS-OFL.txt` is that licence, from CTAN's `amsfonts/doc`. The copy here is the one CSharpMath
ships in `CSharpMath.Rendering/Reference Fonts/`. It is embedded as
`ModeMath.AMS-Capital-Blackboard-Bold.otf`. Its `cmap` reaches only the seven letterlike symbols, so
the generator takes all 26 capitals by glyph id, and fails unless those seven confirm the order.

Both licences require every copy of a face to carry them, so both are embedded beside the faces and
`MathFont.OpenLicenceFile` reads them back: a copy of ModeMath.dll alone is a complete redistribution.

`ModeMath/MathFontData.g.fs` holds the metrics of both, generated by

    dotnet run --project tools/MathTableGen -- fonts/latinmodern-math.otf fonts/AMS-Capital-Blackboard-Bold.otf ModeMath/MathFontData.g.fs

Baked glyph ids only mean anything for these exact files, so the generated data records the length and
SHA-256 of each and a test compares them against the embedded resources. Replacing either means
regenerating.

## Scope

Latin Modern Math is 733,736 bytes: 89% CFF outlines, 3% the `MATH` table, and 2% each of `hmtx`,
`cmap` and `GSUB`. The blackboard face is 8,716 bytes and carries no `MATH` table.

4802 glyphs, of which 2045 are reachable through `cmap` and a further 716 only as stretched variants
or assembly parts of a delimiter. The remaining 2041 are reachable only through `GSUB` features,
mainly `ssty`, which chooses optically heavier shapes at superscript size. ModeMath ignores `GSUB`, so
it sets scripts in the ordinary shapes.

`\widehat` and the wide braces are a separate gap. They grow along the `MATH` table's horizontal
constructions, which MathTableGen parses but does not emit.

The font carries no `MathKernInfo`, so there is no height-dependent script kerning to bake and none is
generated. MathTableGen fails rather than dropping it should a replacement font have any.

Coverage is complete for everything on the roadmap: ASCII, Greek, the math alphabets (bold, italic,
bold italic, sans, mono, fraktur, double-struck), the combining accents, 237 of the 256 mathematical
operators, and 79 arrows. Script lowercase is absent, but `\mathcal` is an uppercase-only command.

Latin Modern's own double-struck alphabet goes unused: it is drawn as thin outlined capitals rather
than the doubled stems the notation calls for. `ℂ ℍ ℕ ℙ ℚ ℝ ℤ` from the Letterlike Symbols block are
drawn from the blackboard face too, so a formula holding either spelling looks the same.
